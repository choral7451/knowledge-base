# knowledge-base

공부한 내용을 주제별로 정리하는 저장소입니다.

## 구조

```
knowledge-base/
├── <주제>/
│   └── <개념>.md     # 한 파일에 한 개념
└── README.md
```

## 작성 규칙

- 폴더는 주제(언어·프레임워크·분야) 단위로 나눕니다.
- 파일 하나에 개념 하나를 담고, 파일명은 소문자 kebab-case로 씁니다.
- 새 글을 추가하면 아래 목록에 링크를 더합니다.

## 목록

- [DDD 정리](ddd/README.md) — 값 객체, 엔티티, 애그리거트, 도메인/애플리케이션 서비스, 포트, 바운디드 컨텍스트, 계층, 디렉토리 샘플
